# 📊 End-to-End E-Commerce Analytics Dashboard

An end-to-end Business Intelligence project built using **Microsoft Excel (Power Query)** and **Power BI**. This project transforms raw e-commerce transaction data into interactive dashboards that provide insights into sales performance, customer behavior, product performance, and marketing effectiveness.

---

# 📌 Project Objective

The goal of this project is to transform raw transactional data into meaningful business insights by performing data cleaning, feature engineering, KPI creation, and interactive dashboard development.

---

# 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query (ETL)
- Power BI
- DAX (Data Analysis Expressions)

---

# 📂 Dataset Overview

The dataset contains approximately **30,000 e-commerce transactions** collected across multiple years.

### Dataset includes:

- Customer Information
- Product Details
- Order Information
- Sales & Profit
- Shipping Details
- Traffic Source
- Payment Method
- Customer Lifetime Value
- Membership Status
- Discount & Tax
- Product Categories
- Geographic Information

---

# 🔄 Data Cleaning & Transformation (Power Query)

The raw dataset was cleaned and transformed using **Power Query** to automate the ETL process.

### Data Cleaning Steps

- Removed duplicate records
- Handled missing values
- Corrected data types
- Standardized inconsistent text values
- Rounded decimal values
- Removed invalid records
- Automated the data cleaning workflow using **Refresh All**

# 📊 Key Business Insights

## Executive Dashboard

- Electronics generated the highest overall revenue among all product categories.
- Saudi Arabia and the United States were among the highest revenue-generating countries.
- Revenue remained relatively stable throughout the year.
- Social Media and Direct traffic sources generated the highest revenue.
- Seasonal revenue distribution was balanced across all four seasons.

---

## Customer Analytics

- Returning customers generated the highest revenue.
- Standard membership customers contributed the largest share of total sales.
- Young Adult customers represented the highest revenue-generating age group.
- Nearly half of the customers belonged to the Low Value segment, indicating opportunities for customer retention and upselling strategies.

---

## Product Analytics

- Electronics was the most profitable product category.
- Fashion recorded the highest quantity sold.
- Home & Kitchen was the second-largest contributor to revenue.
- Profitability varied significantly across different product categories.

---

## Marketing Analytics

- Mobile devices generated the majority of customer orders.
- Social Media delivered the highest revenue among all marketing channels.
- Payment methods showed a relatively balanced revenue distribution.
- Standard membership customers contributed the highest revenue across all membership tiers.
